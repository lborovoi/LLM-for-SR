# Supplementary materials

## Appendix S1: Prompts and Model Settings

The canonical reader copy is
[`appendix-s1-prompts-and-model-settings.pdf`](appendix-s1-prompts-and-model-settings.pdf).
It documents the prompts, review-specific eligibility criteria, output and
parsing rules, model/API settings, and full-text PDF batch rules implemented in
the study code.

This public appendix was extracted from the 17 July 2026 editorial manuscript
version, which is the latest version containing the appendix. Word comments,
collaboration records, and personal document metadata were removed. One
verified typographical correction was applied: `Rode` was corrected to
`Rhone` in the SR3 section heading and criteria label. Prompt logic and
eligibility wording were otherwise preserved as implemented.

Machine-readable prompt files are available in [`../prompts/`](../prompts/).
The checksum for the PDF is recorded in
[`../provenance/checksums.sha256`](../provenance/checksums.sha256).
